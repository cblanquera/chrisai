# ChrisAI Graphics

ChrisAI Graphics creates, plans, and reviews standalone visuals that accompany
or explain content.

Source skill: [`skills/chrisai-graphics`](../skills/chrisai-graphics/SKILL.md)

## Purpose

Use the skill for article banners, cover images, social graphics,
infographics, explanatory diagrams, and technical diagrams. The skill chooses
the layout and medium from the communication job, then uses an available image,
vector, diagram, slide, canvas, or code-based rendering capability.

Software UI/UX, wireframes, interactive design drafts, and design-system
extraction are outside this skill's scope.

## Internal Workflows

- [`banner-and-social-graphics.md`](../skills/chrisai-graphics/workflows/banner-and-social-graphics.md)
  creates single-message article, editorial, and social assets.
- [`infographic-design.md`](../skills/chrisai-graphics/workflows/infographic-design.md)
  analyzes multi-part content, preserves source data, selects a layout, and
  structures an infographic before rendering.
- [`diagram-design.md`](../skills/chrisai-graphics/workflows/diagram-design.md)
  models flows, systems, sequences, relationships, hierarchies, and technical
  architectures with correct labels and connections.
