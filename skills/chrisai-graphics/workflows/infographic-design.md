# Infographic Design

Turn multi-part source content into one structured visual explanation.

## 1. Analyze The Source

Read the complete source before choosing a layout. Identify:

- the main topic
- one to three things the viewer should understand afterward
- the audience's likely knowledge level
- the content structure: sequence, comparison, hierarchy, categories,
  relationships, metrics, or a mixture
- exact facts, quotations, labels, dates, and numbers that must be preserved
- the complexity and number of meaningful points

Do not invent missing data or compress a fact until it changes meaning.

## 2. Structure The Content

Create a concise content plan containing:

- title
- learning objective
- sections or stages
- exact labels and data points
- proposed visual treatment for each section
- source or attribution notes when required

Reduce decorative copy before reducing evidence. If the content remains too
dense, split it into a series or choose a more appropriate document format.

## 3. Select Layout And Style

Use `../references/layout-selection.md` to choose the layout from the
information relationships. Choose style only after the structure is clear.

Match the style to the audience and subject. A technical schematic, editorial
illustration, restrained corporate graphic, or playful educational style can
all work when they support comprehension.

## 4. Confirm Consequential Choices

Before expensive or irreversible rendering, confirm choices that materially
change the output when the user has not already decided them:

- layout
- visual style
- aspect ratio
- language
- rendering approach

Batch these decisions into one concise checkpoint. Skip it when the user has
already specified the choices or explicitly asked for direct generation.

## 5. Render

Persist or present the final structured content and generation specification
before invoking the selected capability. Keep exact text and data traceable to
the source.

If a raster generator cannot reliably render the required text density, switch
to an editable vector, slide, canvas, or diagram medium.

## 6. Review

Apply `../references/visual-review.md`. Verify every label, number,
relationship, and source attribution. Check whether the viewer can follow the
intended reading order without the original article.

If text is wrong or unreadable, regenerate from a corrected specification or
switch media. Do not conceal the error with a bitmap patch.

If feedback requests changes to the rendered infographic, use
`../references/iterative-editing.md` instead of treating the next attempt as a
fresh generation. Return to content structuring or layout selection only when
the feedback changes the underlying information or reading path.
