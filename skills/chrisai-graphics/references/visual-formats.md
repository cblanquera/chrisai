# Visual Formats

Choose format from destination, editing needs, and viewing size. Treat exact
platform pixel specifications as time-sensitive and verify them from current
authoritative sources when publishing requirements matter.

## Aspect-Ratio Defaults

- `16:9` landscape: article banners, presentation-like graphics, video covers,
  and wide link-preview contexts
- `1:1` square: reusable social graphics and balanced single-message cards
- `4:5` portrait: mobile feed graphics that need more vertical presence
- `9:16` vertical: story, reel, short-video cover, or full-screen mobile use
- flexible portrait: long infographics intended for article embeds or
  downloads

Choose one primary ratio before composing. Create purpose-built variants when
the same asset must work in incompatible crops.

## Output Types

- Use PNG for crisp raster graphics, screenshots, and text-forward exports.
- Use JPEG or WebP for photographic or textured web imagery where file size
  matters.
- Use SVG for editable vector graphics, icons, simple diagrams, and exact
  typography when the destination supports it.
- Use PDF for downloadable or document-style graphics when appropriate.
- Use Mermaid or another deterministic diagram source when editability and
  relationship accuracy matter more than decorative styling.

## Text Density

- Banner or social card: one headline or very short message.
- Diagram: concise labels, with explanation outside the nodes.
- Infographic: short sections and data points organized by a visible reading
  path.

If exact copy cannot remain legible at the intended display size, reduce the
copy, split the asset, or choose a document format.

## Accessibility

- Maintain readable contrast.
- Do not encode meaning through color alone.
- Provide alt text or a text equivalent when the destination supports it.
- Keep essential text away from crop and interface-overlay zones.
- Test the exported asset at the size at which readers will actually see it.
