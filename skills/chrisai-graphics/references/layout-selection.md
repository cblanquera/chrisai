# Layout Selection

Choose the layout from the structure of the information.

## Single Message

Use a focal composition, split composition, typographic composition, or one
strong visual metaphor for banners and social graphics.

## Sequence Or Process

Use a linear progression, timeline, numbered path, winding roadmap, or sequence
diagram. Make direction and the starting point unmistakable.

## Comparison

Use side-by-side comparison, before-and-after, comparison matrix, balance, or
Venn diagram depending on whether the content compares attributes, change, or
overlap.

## Hierarchy Or Classification

Use layers, pyramid, tree, nested groups, or periodic-table-like categories.
Show level and containment through position and scale, not color alone.

## Relationships

Use hub-and-spoke, network, Venn, jigsaw, or system map. Reduce crossing lines
and distinguish directional relationships from simple association.

## System Or Architecture

Use structural breakdown, component map, layered architecture, deployment
view, or sequence view. Choose the view that answers the reader's question;
do not combine every architectural perspective into one canvas.

## Cycle

Use a circular flow only when the final stage genuinely feeds the first. Do
not use a cycle merely to make a list decorative.

## Funnel

Use a funnel for filtering, conversion, narrowing, or loss between stages.
Label what changes at each transition.

## Dashboard Or Metrics

Use a dashboard when several measures must be read together. Establish which
metric is primary and preserve units, time ranges, and comparison baselines.

## Dense Overview

Use a modular or bento-style overview only when the sections are independently
scannable. If relationships between modules are essential, choose a more
explicit diagram.
